# Task 17 — Monthly Sales Trend

## Objective
Summarize sales by month and visualize the trend using a monthly table and line chart.

## Tools used
- **Excel** — review the dataset, monthly summary, and line chart.
- **Python** — pandas for date grouping and sales aggregation; matplotlib for the line chart.

## Dataset
`data/retail_sales.csv` is a **synthetic, Superstore-style retail sales dataset created for this practice task**. It is not an official/real customer dataset. It contains Order ID, Order Date, Region, Segment, Category, Product Name, Quantity, Discount, and Sales across January 2023–December 2025.

## Project files
- `data/retail_sales.csv` — input dataset.
- `python/monthly_sales_trend.py` — Python analysis script.
- `output/Monthly_Sales_Trend.xlsx` — Excel workbook with raw data, monthly summary, and line chart.
- `output/monthly_sales_summary.csv` — monthly sales table.
- `output/monthly_sales_trend.png` — generated by running the Python script.
- `README.md` — instructions and findings.

## Run the Python analysis
1. Install Python 3.10+.
2. Open a terminal in this project folder.
3. Install dependencies:
   ```bash
   python -m pip install pandas matplotlib
   ```
4. Run:
   ```bash
   python python/monthly_sales_trend.py
   ```

The script creates/updates the monthly summary CSV and line chart inside `output/`.

## Excel steps
1. Open `output/Monthly_Sales_Trend.xlsx`.
2. In **Sales Data**, check that `Order Date` is a date and `Sales` is numeric/currency.
3. In **Monthly Summary**, review the monthly totals and the line chart.
4. Keep months sorted from earliest to latest. If Excel imports dates as text, use **Data → Text to Columns** or convert them to dates before grouping.

## Key method
Convert Order Date to a valid date, group records by calendar month, sum Sales for each month, sort months chronologically, and plot the totals as a line chart.

## Interview questions — sample answers
**1. What is the best chart for time trends?**  
A line chart is suitable because it shows changes over time and makes increases, decreases, and seasonal patterns easier to notice.

**2. Why can date formatting cause errors?**  
Dates stored as text may not group or sort chronologically. Convert them to true date values and check the day/month format before grouping.
